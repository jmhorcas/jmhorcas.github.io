description: 
  en: "A Latex package that provides syntax highlighting for the Universal Variability Language (UVL). It is based on the listings package and supports all UVL keywords. The package includes multiple visual themes (default, Flamapy, UVLS dark mode, and black & white) and provides inline commands for semantic highlighting. It also supports user-defined features' attributes and the inclusion of external .uvl files."
  es: "Un paquete de LaTeX que proporciona resaltado de sintaxis para el lenguaje UVL (Universal Variability Language). Está basado en el paquete listings y es compatible con todas las palabras clave de UVL. El paquete incluye múltiples temas visuales (predeterminado, Flamapy, modo oscuro de UVLS, y blanco y negro) y proporciona comandos en línea para el resaltado semántico. También admite atributos de características definidos por el usuario y la inclusión de archivos .uvl externos."
